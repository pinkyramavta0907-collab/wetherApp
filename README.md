# 🌤️ Weather App

A responsive weather application that provides real-time weather information for any city.

[Open Weather App](https://pinkyramavta0907-collab.github.io/wetherApp/)

## ✨ Features

- Search weather by city
- Real-time temperature
- Humidity information
- Wind speed
- Weather condition
- Last updated time
- Responsive design

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- WeatherAPI
